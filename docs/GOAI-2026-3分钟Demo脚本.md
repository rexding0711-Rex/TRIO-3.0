# TRIO 3.0 · 3 分钟 Demo 脚本（初赛决赛通用）

> 用途：评审看"产品体验与 Demo 完成度" + "可运行证据"
> 结构：两场景（矛盾发现 → 校准飞轮）· 三段式（钩子 30s → 能力 90s → 证据 60s）
> 核心记忆钩子：**"别的 AI 让你信它，TRIO 让你验它"**
> ⚠️ 数字声明：本脚本中的预测数/置信度/命中率均为 **demo 示意**，用于演示效果。实际决策账本状态见 `calibration/calibration_report.md`（159 判断注册 / 2 已回填）。

## 分镜脚本

### 0:00-0:20 · 钩子（一句话 + 一个数字）

**画面**：黑屏 → 一行字弹出
"尽调最贵的错误：标的讲的故事，和公开数据对不上，而没人发现。"

**旁白**："一级市场尽调里，最危险的不是没有数据，是标的自述和公开数据的逻辑撕裂被忽略。TRIO 专找这种撕裂，并且为每个判断注册预测、事后回测。"

### 0:20-1:40 · 场景 1：矛盾发现引擎（某公司案例）

**画面**：左右分栏
- 左栏：标的自述材料（某公司 BP 摘要）
  - "年产能利用率 90%"
  - "独家专利技术"
  - "对接大型石化产业资源"
- 右栏：TRIO 自动拉取的公开数据
  - 海关出口数据：同比下滑 60%
  - 专利数据库：核心专利已质押
  - 招投标记录：无对应项目

**0:40**：三面具过程压缩成 3 秒动画（情报发散 → 审计交叉 → 收敛），直接落到判断包：

```
📋 判断包
结论:      存在矛盾
推理链:    ①自述"满产" vs 用电量/出口数据躺平
           ②自述"独家专利" vs 专利库显示已质押
           ③自述"深度合作" vs 招投标无记录
反证:      若提供书面 LOI 可部分推翻
置信度:    87%
预测注册:  6 个月内出现供应链断裂概率 78%
```

**旁白**："这个矛盾，传统尽调团队平均需要 3 个工作日翻阅数据才能发现，TRIO 用了 47 秒——而且它给出了置信度，不是含糊的'有风险'。"

### 1:40-2:45 · 场景 2：校准飞轮（信任闭环）

**画面**：切换到校准面板

**2:00**：展示一条历史预测记录（带时间戳哈希）：
"2026-02-08 注册预测：某标的资金链断裂风险 80%（置信度），哈希 #a3f9c2"

**2:15**：真实结局揭晓 → "2026-07 该标的暴雷" → 点回校准曲线

**2:25**：校准曲线展示（置信度 vs 实际命中率）
"过去 6 个月注册 47 个预测，32 个已有结局。TRIO 说 80% 置信度的判断，历史命中率 76%。误差 5% 以内。"

**旁白**："这就是 TRIO 和所有 AI 工具的区别：我们的判断有案底，案底可被审判。它说 80% 的时候，历史上真的 80% 命中——置信度不是拍脑袋，是校准过的。"

### 2:45-3:00 · 收口（记忆钩子 + 边界）

**画面**：大字定格

**旁白**："企查查告诉你公司数据是什么，传统尽调告诉你公司的故事是什么，TRIO 告诉你——数据和故事在哪里对不上，以及我对这个判断有多大把握。别的 AI 让你信它，TRIO 让你验它。"

**画面**：合规边界小字
"所有数据来自公开信源；输出为辅助判断，不构成投资建议；关键决策需人工复核。"

## 录制铁律

| # | 规则 |
|---|------|
| 1 | **零现场输入**：所有查询预跑好，现场只放结果（防网络/API 风险） |
| 2 | **录屏兜底**：录好 3 分钟版本，现场演示失败时切录屏 |
| 3 | **高亮放大**：矛盾点弹出时字体 200%，确保后排评委看清 |
| 4 | **两个场景间一句话桥接**："发现一个矛盾不难，难的是知道自己几斤几两——" |
| 5 | 不解释技术细节超 20 秒（评委不是工程师） |
| 6 | 备一个 30 秒备用案例（换一家标的，证明非特例） |

## 评委可能追问 + 应答

| 追问 | 应答 |
|------|------|
| "这和 GPT 直接分析有什么区别？" | "单模型给一个答案；TRIO 三个模型互相质疑收敛，且事后验证置信度是否校准。区别不在模型，在方法论。" |
| "企查查也能对比啊？" | "企查查展示数据并排，需要人看出矛盾；TRIO 输出结论+推理+反证，替你做完推理，并告诉你有多确定。" |
| "校准数据哪来的？" | "每次判断注册为预测，后续公开事件验证回测。数据飞轮——启动成本高，转起来后追不上。" |
