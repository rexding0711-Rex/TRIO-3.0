## 一、项目定位(一句话)

**TRIO 3.0 — 会自我校准的多 Agent 金融决策系统**:
面向一级市场尽调与投研场景,通过三面具协同(发散/审计/收敛)+ 决策校准飞轮(预测注册→回测→置信度修正),把 AI 从"分析工具"升级为"可验证、可审计、越用越准的判断者"。

## 三、技术架构(三面具 → 金融 Agent 闭环)

```
输入: 尽调对象资料(公司资料/人物/行业)
  ↓
主控 Agent(任务拆解)
  ├─ Kimi 面具(情报): 行业全景 + 竞品初筛 + 反例搜索
  ├─ DeepSeek 面具(审计): 事实核查 + 置信度标注 + 交叉验证
  └─ Claude 面具(收敛): 综合判断 + 判断包产出
  ↓
判断包: 结论 / 推理链 / 反证 / 置信度[1-5] / 预测注册
  ↓
决策校准飞轮:
  预测注册(falsification_date) → 回测(verified/falsified) → 校准曲线 → 置信度修正
  ↓
下次判断更准
```

## 四、差异化杀手锏:决策校准飞轮

**大多数 Agent 只做"干活"**,TRIO 做"干活 + 知道自己干得对不对 + 越用越准":

```
预测注册 → 结果回测 → 校准曲线(置信度 vs 命中率) → 置信度修正
```

**示例**(真实案例): 面对声称"政府估值1.7亿"的合作方,TRIO 输出"不合作"判断 + 注册预测"若继续接触30天内无书面证明→判定叙事方坐实" → 回测 → 校准该类型判断的置信度。

**价值**: 金融决策最怕"过度自信"。校准飞轮让系统**知道自己的判断边界**,这是普通聊天机器人做不到的。

## 五、Skill 清单(可复用能力 · 6 个流水线)

> 2026-08-11 扩展(吸收 GOAI 外部评审): 从 4 个扩到 6 个,形成**首尾相接的完整流水线**——声明抽取 → 信源分级 → 信号识别 → 估值验证 → 判断包 → 预测校准

| Skill | 用途 | 输入→输出 |
|-------|------|----------|
| **声明抽取**(新增·最高优先) | 把非结构化 BP/档案 → 结构化声明清单(命中官方"文档理解"定义) | 尽调资料→声明清单(声称X/出处Y/可验证性Z) |
| **信源分级**(新增) | 每条证据标信源类型(官方/司法/自述/转述) | 证据→信源可信度分级 |
| 尽调信号识别 | 识别不靠谱合作方(老登模型) | 合作方资料→风险评分+红旗信号 |
| 估值交叉验证 | 验证声称估值/资源真实性 | 声称→验证清单→置信度 |
| 判断包生成 | 结构化输出金融判断 | 分析材料→结论/推理/反证/置信度/预测 |
| 预测校准 | 回测+校准曲线(按判断类型分桶) | 历史预测→校准报告 |

## 六、Demo 设计(初赛可展示)

**输入**: 一份虚构/脱敏的公司尽调资料
**输出**: 
1. 三面具独立分析(可展开)
2. 结构化判断包(结论/推理/反证/置信度/预测契约)
3. 注册可证伪预测(带 success/failure 条件)
4. 校准曲线(证明系统会自我修正,按类型分桶)
5. **追问清单**(评审强调的闭环能力: 生成"向对方索取X文件/在Y系统核查Z")

## 七、开源与合规
