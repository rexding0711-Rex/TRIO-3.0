# TRIO 技术文档 + 提交物核对清单

> 用途：提交物技术部分 + 逐项核对（初赛 8/16 截止）
> 原则：不以概念展示为终点，以真实问题、完整闭环、可验证价值为核心

---

## 一、架构（文字版）

```
输入: 标的自述材料 + 公开数据（工商/年报/专利/招投标/海关/司法）
  ↓
理解: 实体与关键声明抽取
  ↓
编排: 三面具协同
   ├─ 情报面具(Kimi): 发散搜索 + 反例 + 红旗信号
   ├─ 审计面具(DeepSeek): 交叉验证 + 规则匹配(contradiction_rules.json) + 矛盾标注
   └─ 收敛面具(Claude): 综合判断 + 判断包输出
  ↓
结果: 判断包（结论/推理链/反证/置信度/预测注册）
  ↓
异常验证: 置信度低于阈值 → 标"需人工复核"; 数据源缺失 → 降级提示
  ↓
校准: 预测注册 → 回测 → 校准曲线 → 置信度修正
```

## 三、异常处理

| 异常 | 处理 |
|------|------|
| 数据源缺失 | 降级提示"该维度无公开数据，置信度降级" |
| 材料格式异常 | 解析失败 → 提示补充材料 |
| 三面具结论冲突 | 触发"矛盾裁决"机制，输出分歧点 + 置信度区间 |
| 模型幻觉 | 判断包强制含"反证"字段；低置信度标记需人工复核 |
| API 超时 | 缓存 + 重试 + 降级到本地规则 |
