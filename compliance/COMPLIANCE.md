# TRIO 合规披露

> 用途：提交物合规部分（数据来源/隐私/边界/免责/偏见声明）
> 金融赛道评审重点关注——缺失可能一票否决

---

## 一、数据来源清单

| 数据类别 | 来源 | 获取方式 | 合规依据 |
|---------|------|---------|---------|
| 工商信息 | 国家企业信用信息公示系统 | 公开查询 API | 政府公开数据 |
| 财务数据 | 上市公司年报/财报 | 交易所公开披露 | 法定义务披露 |
| 司法记录 | 中国裁判文书网/执行信息平台 | 公开检索 | 司法公开 |
| 专利状态 | 国家知识产权局 | 公开查询 | 专利公开 |
| 失信/限高 | 最高法院名单 | 公开查询 | 执行信息公开 |
| 招投标 | 政府采购/招投标平台 | 公开检索 | 交易信息公开 |
| 海关统计 | 海关总署公开数据 | 公开数据 | 统计公开 |
| 舆情/新闻 | 公开媒体报道 | 检索整理 | 公开信息 |

**原则**：仅使用公开可获取数据；不抓取受版权保护内容；不采集个人敏感信息。

## 二、隐私处理

- **输入**：仅处理企业公开商业信息，不涉及个人隐私数据
- **存储**：不留存原始材料；中间结果脱敏后用于评测
- **删除机制**：用户上传材料可随时删除，不用于模型训练
- **审计**：判断过程可追溯（预测契约带时间戳哈希）

## 三、应用边界

- TRIO 是**辅助尽调工具**，输出为判断参考，**不构成投资建议**
- 关键决策（投资/签约）需人工复核
- 明确不做的：
  - 不做二级市场实时交易信号
  - 不替代法律/审计/评估机构签字
  - 不提供确定性结论（输出带置信度）

## 四、免责声明

- 本系统基于公开数据与算法推理，判断可能存在错误（见评测报告误报率）
- 任何决策后果由使用者承担，与系统开发者无关
- 输出内容受算法不确定性影响，请结合专业判断使用

## 五、模型偏见声明

- 三面具协同降低单一模型偏见，但无法根除（共享训练数据先验）
- 校准飞轮持续修正置信度偏差，但校准样本有限时误差仍存在
- 已知局限：对"财务数据自洽但事实造假"（如无公开矛盾点）的标的，检出能力有限
- 误判后果：宁可漏报不误报（保守策略），漏报点会在评测报告中显式标注
