# TRIO 3.0 · 尽调矛盾发现引擎

> **别的 AI 让你信它，TRIO 让你验它。每个判断都有案底，案底可被审判。**

---

## 30 秒钩子

某公司说自己有 500 强产业资源、政府估值 1.7 亿。
TRIO 用 22 条规则、47 秒发现：他的"战略合作方"公开记录查无实据、他的信用记录有硬伤、他要的关键材料始终不给。
6 类矛盾，置信度 0.77。这不是"信息不足"——这是**逻辑撕裂**。

## 一句话定位

企查查告诉你公司数据是什么，TRIO 告诉你**数据和故事在哪里对不上**——并告诉你有多大把握。

- 企查查/天眼查 = **图书馆**（你查什么它给什么，矛盾要你自己看出来）
- 通用 LLM = **建议器**（给结论，从不验证）
- TRIO 3.0 = **审讯官**（主动交叉比对，找出"说的"和"事实"的撕裂，并为自己判断负责）

## 快速开始（可运行 · 一键体验）

```bash
# 一键尽调（clone 后直接运行：输入你要尽调的企业情况与附件）
python src/main.py

# 或直接指定模式：
python src/main.py --demo                        # 跑某公司演示案例（已跑通）
python src/main.py --input 材料.txt              # 自定义尽调材料
# 示例输出见 output_samples/target_output.json（命中 6 类矛盾，置信度 0.77）

# LLM 语义增强（可选，需 API key）
export DEEPSEEK_API_KEY=xxx
```

## 状态声明（demo）

本项目为 **demo 级开源资产**，非生产系统。展示页规模数字（6,348/78%/5,198）为**产品愿景示意**，非决策账本数据；实际状态见 `calibration/` 与 `predictions/`。

## 评测（诚实版）

- **机制演示**：规则引擎（红旗候选生成器）对 10 个演示案例（5 暴雷 + 5 正常）全部正确判定（详见 `benchmark/results/result_summary.md`）。
- **⚠️ 诚实声明**：演示性案例材料，非真实性能验证；规则引擎定位是"候选生成"，最终"自述 vs 公开数据"矛盾确认由 LLM 层完成（需 API key）。
- **已真实跑通**：某公司尽调案例（真实场景材料）命中 6 类矛盾，输出完整判断包。
